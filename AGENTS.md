# Инструкции для ИИ-ассистентов (AGENTS.md)

Этот файл определяет строгие архитектурные правила проекта. **Любой код, нарушающий разделение слоев, считается невалидным.**

## 1. Архитектура и структура слоев
Проект построен на строгом разделении ответственности. Запрещено смешивать транспортный слой, валидацию и работу с базой данных в одном файле.

* **`/routers` (или `/api`) — ТОЛЬКО HTTP-слой:**
  * Прием запроса, вызов зависимостей (`Depends`), вызов методов DAO/сервисов и возврат ответа.
  * **СТРОГО ЗАПРЕЩЕНО:** писать SQL-запросы, вызывать методы сессии БД/Redis напрямую или объявлять Pydantic-модели внутри файлов роутов.
* **`/schemas` — ТОЛЬКО Pydantic-модели:**
  * Все схемы запросов (`*Create`, `*Update`, `*Request`) и ответов (`*Response`, `*Out`) должны находиться исключительно здесь.
  * Наследуйтесь от базовых схем проекта. Используйте строгую типизацию полей.
* **`/dao` (Data Access Object) — ТОЛЬКО работа с БД и кэшем:**
  * Все операции с базой данных (SQL / ORM) инкапсулируются в отдельные DAO-классы (эталон реализации: `dao/social.py`).
  * DAO-классы не должны знать о HTTP-запросах (не импортировать `HTTPException`, `Request` и т.д. из FastAPI).

## 2. Правила оформления Python-кода
* **Типизация:** Обязательны аннотации типов для всех аргументов функций и возвращаемых значений (включая `-> None`).
* **Асинхронность:** Все операции ввода-вывода (БД, Redis, внешние HTTP-запросы) должны быть строго асинхронными (`async/await`).
* **Именование:**
  * Классы (включая DAO и Pydantic-схемы): `PascalCase` (например, `UserDAO`, `UserCreateSchema`).
  * Методы, функции, переменные, модули: `snake_case`.
* **Обработка ошибок:**
  * HTTP-исключения (`HTTPException`) выбрасываются только на уровне роутов или сервисов, но **никогда** внутри DAO. DAO возвращает `None`, пустой список или выбрасывает доменное исключение.

## 3. Тестирование
* Тесты должны проверять работу с testcontainers (тестовая БД / Redis) там, где это возможно, без избыточного мокирования внутренних методов DAO.
* Для каждого нового метода в DAO должен быть написан соответствующий тест.

## 4. Чек-лист перед выдачей кода (Self-Correction)
Перед тем как предложить решение, проверь себя:
1. Нет ли в файле роута объявлений `class SomeModel(BaseModel)`? (Если есть — перенеси в `schemas/`).
2. Нет ли в файле роута обращений к БД? (Если есть — вынеси в класс в `dao/`).
